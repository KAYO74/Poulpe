# Maquette de l'interface

`maquette-v3.html` est la maquette interactive v3 de Poulpe Design (4 octobre 2026). C'est un fichier HTML autonome : ouvrez-le dans un navigateur pour l'essayer.

Elle montre une fenêtre d'application de bureau façon Affinity : menus, barre d'outils principale, barre contextuelle, colonne d'outils (à droite par défaut), Studios ancrables, Personas Dessin / Photo / Mise en page, réglage « Personnaliser », langues français et anglais.

Elle sert de référence visuelle pour le moteur d'édition v0.1 ; ce n'est pas le code de l'application.
